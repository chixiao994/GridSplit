# GridSplit

一个极简的 Android 图片网格分割工具。逐张预览图片，点击「下一张/保存」即按指定的行×列把当前图片切成小块写入输出文件夹；点「跳过」则不做任何处理，直接进入下一张。

> 只有一个功能：网格分割。没有广告，没有多余权限，不联网。

## 功能

- 选择输入文件夹 / 输出文件夹（基于 SAF，无需存储权限）
- 递归扫描输入文件夹内的所有图片，按文件名排序
- 自定义分割行数、列数（1 ~ 50）
- 预览图片并叠加红色分割参考线
- 上一张 / 跳过 / 下一张（保存）
- 保存时自动读取 EXIF 旋转信息，按正确方向切割
- 切块以 PNG 格式输出，文件名自动追加行列后缀，避免覆盖
- 自定义 App 图标（网格分割主题，不再是默认机器人）

## 下载

1. 打开本仓库的 **Actions** 页面。
2. 选择最新的 **Build APK** 工作流运行记录。
3. 在页面底部的 **Artifacts** 中下载 `gridsplit-debug-apk`。
4. 解压得到 `app-debug.apk`，传到手机上安装即可。

> 这是 debug 签名包，仅供个人测试使用。

## 使用方法

1. 安装并打开 App。
2. 点击「输入文件夹」选择要处理的图片所在目录。
3. 点击「输出文件夹」选择切块保存位置。
4. 输入分割的 **行数** 和 **列数**，预览区会实时显示分割参考线。
5. 使用底部按钮逐张处理：
   - **上一张**：回到上一张图片，不保存。
   - **跳过**：不处理当前图片，直接进入下一张。
   - **下一张/保存**：按当前行列切分并写入输出文件夹，然后自动进入下一张。
6. 处理到最后一张时会提示完成。
